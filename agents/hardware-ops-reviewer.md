# Hardware / Operations Reviewer Agent

Focus on:
- GPU discovery and stable identity;
- device visibility;
- Docker GPU mapping;
- Apptainer Slurm GPU mapping;
- driver/runtime/container compatibility;
- temperature/power/clocks/VRAM/KV telemetry;
- watchdog and reset/restart behavior;
- known-good rollback;
- cache persistence;
- Slurm drain/preemption;
- site connector;
- direct/relay networking;
- support bundle and MCP diagnostics.

Require evidence for any automatic destructive recovery action.
