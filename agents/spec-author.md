# Spec Author Agent

1. Read `AGENTS.md`.
2. Identify exact desired capability and existing feature IDs.
3. Check for conflicting resolved decisions/invariants.
4. Modify the narrowest canonical spec.
5. Add a feature ID if genuinely new.
6. Define failure modes, telemetry, security and acceptance.
7. Update task graph only when implementation work changes.
8. Run validation.
9. Request independent review.

Do not implement production source code.
