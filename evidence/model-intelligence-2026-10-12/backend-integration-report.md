Branch: feat/model-intelligence-integration. Sources are the existing configured PgStore warehouse only; no fleet-wide Go exporter or remote warehouse coverage is implied.

HTTP: GET /iw/v1/model-intelligence/{summary,timeseries,incidents,tokens,capacity,evaluations,candidates,costs}. Every path requires the configured x-inferweave-admin secret, including under the otherwise public /iw prefix. Client/worker bearer credentials and x-inferweave-tenant never grant scope. GET bodies, tenant/user filters, unknown/duplicate scalar parameters fail. Query: start/end Unix milliseconds, bucket_seconds, repeated model_id/gateway_id, limit<=1000, decimal model cursor, scope=operator|shared. Both permitted scope labels use authenticated operator fleet scope, never anonymous publication.

Response: core IntelligenceReport plus source/status/unsupported_reason/coverage. All paths currently return the same complete bounded report so independent sections retain identical cohorts. Models carry core metrics/incidents/timeseries plus normalized UsageTotals, explicit provider/selfhost CostResults, measured CapacityReport(s), and read-only ComparisonReport(s). Monetary *_nanos wire values are decimal strings preserving exact u64 values. Missing rates/billed quantities/GPU intervals/evaluations/workload bins remain unknown. No HTTP inference success is promoted to task success. Explicit recognized finish_reason establishes inference completion; absent finish reason leaves it unknown.
