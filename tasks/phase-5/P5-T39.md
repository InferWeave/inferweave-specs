## Outcome
Implement `iw.site-attestation/1` in the Rust gateway and node (InferWeave/inferweave). The gateway
loads a private paid-grant policy and enforces each grant with default-deny before admission; it puts
the capability in force only with a valid loaded policy; it answers a node's heartbeat `siteAttestation`
request with a short-lived attestation bound to the instance, the gateway and the grant digest, or a
closed-set refusal. The node registers without its paid model, requests and verifies an attestation
against its trusted gateways, advertises the model only while it holds an acceptable one, refreshes it
before expiry with the link held, and withdraws it on expiry or refusal. It works against any gateway
and for any number of scheduled or restarted instances.

## Required tests
- the capability is listed only with a loaded, valid paid-grant policy, and an invalid policy is absent
- every refusal code is produced by exactly its condition, in the stated order, and a refusal is never an empty success
- an attestation is issued only to an enrolled, fresh registration; a key-only identity gets `not_enrolled`
- two instances with different node ids are each attested for one grant, and a copy of one is refused by the other, by another gateway id and by another grant digest
- the gateway refuses a request for the model from any subject other than the grant's before admission
- the site does not advertise the paid model before an attestation, withdraws it at expiry and on refusal, and re-requests before expiry with the link held
- the site never falls back to an older attestation or a file while the capability is in force
- `any` is accepted only when configured explicitly

## Operational evidence
Owed. A real paid-runtime site on a Slurm node joining a Rust gateway: attested, advertised, restarted
by its scheduler without a person, and re-attested; the same site joining a second gateway; a
policy-less gateway refusing and the site staying unadvertised. No operational claim is made.

## Scope discipline
Implement only this outcome. No deployment, enrollment, key issuance or production traffic is
authorized. The paid vendor credential, pricing and metering are non-goals (specs/67 section 8).
Retiring the Go gateway's paid-policy path is a separate, later change.
