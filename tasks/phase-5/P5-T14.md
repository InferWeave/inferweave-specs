## Outcome
A gateway can ask a peer for capacity on the control plane without holding the triggering client request: negotiation runs on its own clock, a peer answers or refuses immediately with a spec 06 reason code, and no peer offers capacity it has already granted elsewhere.

## Required tests
- client request is not held beyond the spec 06 admission budget while a peer is asked
- a peer with outstanding grants does not offer the same capacity twice
- refusal is immediate and carries a reason code
