## Outcome
Capacity requests carry a path vector and hop budget and are bounded by a configured fan-out breadth, so one shortage cannot broadcast across a mesh and a malformed path causes refusal rather than an unbounded walk.

## Required tests
- a request whose path already contains the receiver is refused
- a request at hop budget zero is answered or refused, never forwarded
- fan-out never exceeds the configured breadth
- a malformed path vector causes refusal, not traversal
