## Outcome
Expected device inventory is derived from discovery and versioned with the hardware fingerprint; a device count or identity change triggers a new host generation and requalification instead of a permanent degraded state.

## Required tests
- node with fewer cards requalifies rather than degrading permanently
- device change creates a new host generation
- context ceiling re-derived for the new generation
- no silent CPU fallback on missing devices

## Operational evidence
A hard-coded expected device count cannot survive a rebuild.
