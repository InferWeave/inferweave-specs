## Outcome
Compare a pinned golden set run greedy with recorded seeds, pairwise over time per series: exact-match rate, first-divergence index, normalized edit distance and flip rate, with an alarm rule that refuses to alarm without a measured same-stack self-divergence floor. Alarms use the exact McNemar tail on paired flips, Holm correction, one-sided EWMA and CUSUM on continuous series, and require two consecutive runs or a fingerprint change plus a statistical signal. Verdicts are Ok, Watch, Alarm or Unverified. Golden outputs are versioned and a deliberate stack change starts a new series. The result is evidence only and never changes routing eligibility.

## Required tests
- an alarm rule cannot be built from a floor with fewer than the minimum number of items
- a comparison below the minimum trial count is Unverified, not Ok
- an impossible comparison (mismatched item sets or series) is refused by the rule itself
- a single exceedance does not alarm; two consecutive runs do
- Holm correction is applied across the last two comparisons and no wider claim is made
- the drift alarm command exits 1 on an alarm and 2 on a refusal or usage error
