# P0 Mandatory code audit and deduplication
Inspect git SHA, branches, PRs, docs/specs, Rust crates, existing Go routes, runtime registry, model aliases, profiles, rebalancer, GPU accounting, CPU scheduling, Slurm/Apptainer, multi-parent federation, SDKs, tests, UI and CI. Locate Oct 8 Universal Runtime, Oct 9 Architecture Consolidation and Oct 10 Federated Model Provisioning master specs; reconcile with actual code.
Create evidence/inventory.json, evidence/capability-ledger.yaml, evidence/contract-map.yaml, evidence/duplicate-map.md, evidence/baseline.md, evidence/decisions.md, evidence/dependency-dag.md. For each capability: source path/line, SHA, owner, current behavior, test, status (complete/partial/missing/duplicated/unknown), decision, migration, rollback. Unknown is not missing. Decision preference: reuse > extend > consolidate/refactor > add new. No implementation before audit gate. Baseline tests with timeouts and logs; no indefinite hangs.
