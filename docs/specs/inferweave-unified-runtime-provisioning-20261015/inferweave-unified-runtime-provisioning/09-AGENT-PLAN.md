# Autonomous multi-agent work
Supervisor audits first, then creates dependency DAG and nonoverlapping Pi agent missions: contracts, ledger, runtime adapters, profiles/placement, federation/Slurm, UI, QA. Contracts before consumers; serialize shared crate edits. Verify model slots and choose capable Qwen/DeepSeek models if available per current policy; do not assume availability. Each worktree mission gets paths, no-touch paths, acceptance tests, rollback, heartbeat, progress logs, reviewer and handoff. Handoffs record SHA, diff, decisions, tests, blockers and next exact step instead of lossy compacting. Independent review and merge gates; clean merged worktrees and stale builds safely.
