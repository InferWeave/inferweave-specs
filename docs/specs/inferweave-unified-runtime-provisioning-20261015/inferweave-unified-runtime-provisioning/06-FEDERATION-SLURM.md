# Owner-controlled federation and HPC
Opt-in modes disabled (default), advertise_only, approval_required, autonomous. Owner policy: parent identities, model digest/license, runtime, CPU/GPU quotas, reserve, priorities, privacy, preemption, maintenance, emergency stop. Version negotiated protocol messages: capacity, request, offer, approve, reserve, commit, status, renew, revoke, release. Advertisements are not guarantees; leases scoped, expiring and fenced. Multi-parent cannot double allocate, topology cycle/replay protected. Local clients retain owner-defined priority.
Slurm/Apptainer adapters report queued/wait reason, allocated, staging, downloading, loading, warming, ready, draining, preempted, failed, cleanup. Report actual job IDs and limits, no invented ETA. Surface in Rust API and Go UI. Fault-test partitions, retries, duplicate commits, Slurm preemption, owner revocation and node crashes.
