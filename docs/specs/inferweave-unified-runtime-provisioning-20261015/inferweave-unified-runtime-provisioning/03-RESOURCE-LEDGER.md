# CPU, GPU, hybrid and memory accounting
Discover CPU physical/logical cores, ISA, NUMA, RAM, bandwidth, GPU vendor/device, CUDA/ROCm/Metal/Vulkan, VRAM, partitions, driver, power/thermal, disk, Slurm allocations. Record allocatable capacity, OS reserve, peak transient memory, KV cache, concurrency, context size, pinned buffers, fragmentation, model weights and warm pools. Apple Silicon RAM/VRAM share ONE physical backing pool; do not double count. CPU-only nodes advertise zero GPUs, never fake VRAM.
Reservations: request ID, tenant/owner, model digest, profile hash, resource claims, priority, TTL, fencing epoch, generation, state. Distinguish advertisement/offer/reservation/commit/ready. Atomic CAS, idempotent renew/revoke/release, crash recovery and multi-parent double-spend prevention. Test simultaneous admissions, overcommit, memory pressure, stale offers, node loss, lease expiry, NUMA and unified-memory accounting. Expose explainable reservation traces and historical metrics.
