# Ownership and invariants
One Rust authoritative inference control/data plane; existing rebalancer sole accelerator allocation authority, integrated with one transactional CPU/RAM/GPU/VRAM ledger. Go gateway only UI, edge authentication and transparent relay, no independent model routing/placement. Canonical versioned APIs in inferweave-specs, conformance fixtures and generated clients. Preserve existing traffic and public API. Multi-parent owner-local resource authority. Remote provisioning disabled by default, no arbitrary remote commands. Self-hosted/open-weight default, no silent proprietary fallback. Rollout by feature flag, shadow, canary and reversible migration. Do not remove Go behavior until Rust parity proven.
